# BrandMyStore MVP

A static marketplace MVP for BrandMyStore.com.

## What is included

- Responsive landing page
- Marketplace listing cards
- Search and filters
- Category browsing
- Listing detail modal
- Brand brief form
- Space owner submission form
- Email based lead capture using hello@brandmystore.com
- Mobile responsive design

## Launch with GitHub Pages

1. Create a new GitHub repository, for example `brandmystore`.
2. Upload `index.html`, `styles.css`, and `script.js` to the root of the repository.
3. In GitHub, open Settings, then Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select `main` and `/root`, then Save.
6. Add `www.brandmystore.com` as the custom domain once your DNS records are ready.

## Before launch

Replace the demo marketplace listings in `script.js` with real spaces as they join.

The forms currently use `mailto:hello@brandmystore.com`. For a proper database or CRM flow, the next version can connect to Supabase, Airtable, Formspree, HubSpot, or a custom backend.
